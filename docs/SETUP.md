# Setup V10

1. Copier `.env.example` en `.env`
2. Coller tes clés Discord
3. Créer un salon `#veille-ia-dev`
4. Copier son ID dans `INTELLIGENCE_REPORT_DISCORD_CHANNEL_ID`
5. Créer une clé OpenAI API
6. Coller la clé dans `OPENAI_API_KEY`
7. Lancer `npm install`
8. Lancer `npm run deploy`
9. Lancer `npm run dev`
